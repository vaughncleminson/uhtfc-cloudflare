* How to Export database from cloudflare D1 and restore locally
# 1) Stop dev server first

# 2) Export prod D1 to a single variable (avoid filename mismatch)
DUMP="./database-exports/prod-$(date +%F-%H%M%S).sql"
npx wrangler d1 export d1-uhtfc-cloudflare --remote --output="$DUMP"

# 3) Reset local D1 state
rm -f .wrangler/state/v3/d1/miniflare-D1DatabaseObject/*.sqlite

# 4) Recreate empty local DB file
npx wrangler d1 execute d1-uhtfc-cloudflare --local --command "SELECT 1" >/dev/null

# 5) Import using Wrangler (preferred over direct sqlite file plumbing)
npx wrangler d1 execute d1-uhtfc-cloudflare --local --file "$DUMP"

# 6) Verify key tables
npx wrangler d1 execute d1-uhtfc-cloudflare --local --command "SELECT COUNT(*) AS admins_count FROM admins;"
npx wrangler d1 execute d1-uhtfc-cloudflare --local --command "SELECT name FROM sqlite_master WHERE type='table' AND name LIKE '%migration%';"
